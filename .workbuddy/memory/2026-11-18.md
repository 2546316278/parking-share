## shared-parking 目录结构整理（阶段 1 收尾）

### 整理前的问题
1. `D:/停车场/shared-parking` 存在一个误建的空目录，与新项目同名，易混淆 —— 已 `rmdir` 删除
2. 根目录 `models/`（YOLO 权重）与未来 `server/models/`（ORM 模型）同名，语义冲突
3. `data/make_demo.py` 是临时验证脚本，却放在数据目录里，且硬编码绝对路径
4. `data/` 根目录混放运行期数据与自测合成图
5. `requirements.txt` 单文件混装视觉/服务/实验三组，`pip install -r` 有装坏 CUDA 版 torch 的风险
6. 大量空目录（server/*、web、experiments、tests、sql）git 不追踪，clone 后结构缺失

### 整理后的结构
```
shared-parking/
├── vision/       config / calibrate / detector / smoother
├── server/       models / routes / services
├── web/          Vue 3
├── experiments/  论文对比实验（outputs/ 不入库）
├── scripts/      一次性脚本（make_demo.py）
├── tests/ sql/ docs/
├── weights/      YOLO 权重（原 models/，不入库）
├── data/         videos / calibrations / snapshots / samples
└── requirements/ vision.txt / server.txt / dev.txt
```

### 关键改动
- `vision/config.py`：`MODEL_DIR = BASE_DIR/"models"` → `WEIGHT_DIR = BASE_DIR/"weights"`，并新增 `SAMPLE_DIR`
- `vision/detector.py`：`resolve_model()` 改用 `cfg.WEIGHT_DIR`
- `scripts/make_demo.py`：改为基于 `Path(__file__).parent.parent` 定位，新增 `--car` 参数，车辆素材自动从 `data/samples/` 挑选非 `demo_` 开头的图
- `requirements.txt` 拆三份，根文件只 `-r requirements/server.txt` + `-r requirements/dev.txt`（视觉组需手动逐条装）
- 新增 `docs/STRUCTURE.md`：目录职责表、命名约定、scripts vs experiments 区别、新增文件该放哪
