## 目录重组为 backend / frontend / databases（11:44 完成）

用户要求按技术类型分类，新建 parking 式结构。最终落地：

```
shared-parking/
├── backend/
│   ├── vision/      视觉检测服务（原 vision/）
│   └── flask/       Flask 业务后端（原 server/，含 models/routes/services）
├── frontend/        （原 web/）
├── databases/       （原 sql/）
├── docs/ scripts/ tests/ experiments/
├── weights/ data/ requirements/
```

### 关键决定
- **没有**在 backend 下建 flask/springboot/fastapi 三套并列。理由：技术栈已定稿 Flask，
  另两套会永久空着；springboot 是 Java，与 Python 依赖体系不兼容。已向用户说明。
- **vision 没有塞进 flask**。理由：YOLO 模型加载慢会阻塞 Flask 启动；模型非线程安全；
  检测服务崩溃不应拖垮 Web。与 TECH_STACK.md 的 D1 决策一致。
  用户提到"把模型放 flask 里"，已解释，等他后续讲业务需求时再确认是否调整。

### 技术要点
- `backend/vision/config.py`：`BASE_DIR` 从 `VISION_DIR.parent` 改为 `VISION_DIR.parent.parent`
  （多嵌套一层），新增 `BACKEND_DIR`
- `scripts/make_demo.py` 的 `BASE_DIR` 不用改（scripts 仍在根目录下）
- 用 `git mv` 迁移，30+ 个文件的 git 历史完整保留（git status 显示为 R 重命名）
